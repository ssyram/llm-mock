# Bedrock ConverseStream：组装对照协议

> 发布版脱敏说明：机器路径、私有 provider、会话/调用标识及采集时间已替换为占位或合成值；保留技术形态与历史统计，不作为逐字原始转录。

## 1. 概览

**权威与范围。** TS 路径均相对只读根 `<pi-mono>/packages/ai/src`；`src/`、`tests/`、`docs/` 均相对 mock-with-pi。源码是行为权威，旧文档及 canonical 只作待核对对象。本页仅定义 Bedrock；Mistral 已迁至 mistral.md，旧合并页仅为退役存根。请求输入全集为 `types.ts:414–467,541–639`、`types.ts:157–261` 与 `api/bedrock-converse-stream.ts:79–111`。

**组装方向。** Q＝统一 transcript/options → pi convert → SDK wire → mock decode；R＝统一 AssistantMessage → mock encode → SDK 解包 → pi parser。精确往返指 JSON 值语义及图像/opaque 字节相等，不要求 JSON 键序或网络分片相同。沿用 `../irreversibility-atlas.md` 的 E/D/L/P/T：**精确往返 E**；**确定性变换 D**（本页列明规则）；**丢弃 L**（当前组装不把原字段送入 wire）；**pi 注入 P**（客户端身份、时间、成本等盖章）；**transport 阻断 T**（内容解析前传输失败；输入契约拒绝和已收内容后的流内失败不是T）。wire 有字段但 mock 不读的情形记 **D（mock 缺口）**，绝不冒称 L 或协议固有损失；分类按字段、方向和条件，不按协议一刀切。

## 3. 回复方向字段映射表

## 4. canonical form

**O18 / R 统一签名投影（owner裁决，现行）**：Bedrock接入同一出口但使用Opaque域：R原生thinking signature/redacted bytes保留，不因Responses/OCC/Mistral的签名域限制全局剥除；本页既有R规则不变。 统一实现：`src/api/encode_thinking.rs:18–90`；跨源明文规则依据`api/transform-messages.ts:95–116`、`api/openai-responses-shared.ts:179,264–289`、`api/anthropic-messages.ts:1168,1443–1483`、`api/google-generative-ai.ts:374`→`api/google-shared.ts:200,234–266`。这只判目标签名支持域，不做基于reply身份的TM全量转换；历史summary-item降级草案被text规则取代。完整证据/18案复跑见`../o18-resolution.md`与图谱B2。

## 5. 不可逆声明与 transport 边界

### Options 槽位镜像补充（本轮裁决）

- auto/any恢复字符串，具名tool choice从wire.tool.name恢复原生{type:tool,name}对象（E）；none/无tools仍不发，不补猜（api/bedrock-converse-stream.ts:82,1153–1182；src/api/bedrock_converse_stream/decode.rs:12–26）。

W-07已实施工具结果图片与reasoning扩展补读，§2/§4为同步后的当前定义；其余strict/cachePoint/requestMetadata及transport仍仅候选，模型扩容须另批。W-07实现验证见../w07-implementation.md；W-08的oracle对齐与终跑结果见../w08-match.md，以下旧oracle差异属于历史登记，不作当前未修声明。
